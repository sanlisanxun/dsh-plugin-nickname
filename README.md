# dsh插件名称修改

[English](README.en.md) | 中文

给 DeepSeek Harness (dsh) 插件列表里的插件自定义中文备注名，直接显示在原生插件设置页。

## 功能

- 自动把插件列表里的英文包名替换成自定义中文备注
- 可视化编辑面板：左下角「📝 备注」按钮，或按 `Ctrl+Shift+N` 打开
- 自动扫描当前已安装的所有插件，直接编辑备注
- 备注保存在浏览器 localStorage 里，永久生效
- 鼠标悬停在备注名上会显示原来的英文包名

## 安装

### 方式一：GitHub 仓库直接安装（推荐）

桌面端（DSH 0.2.0-rc.2）：在侧栏打开「插件 → 添加插件」，粘贴下面的地址，安装后选择「立即启用」。若应用提示需要重启，按提示操作。

```
github:sanlisanxun/dsh-plugin-nickname
```

### 方式二：本地目录安装

1. 下载本项目，解压到本地文件夹
2. 打开 dsh → 插件 → 添加插件
3. 输入本地文件夹的完整路径，点安装
4. 刷新页面生效

## 使用

安装后：
- 点左下角的「📝 备注」按钮，或按 `Ctrl+Shift+N` 打开编辑面板
- 在输入框里直接改中文名字，按 Tab 键保存
- 留空则恢复原来的英文包名
